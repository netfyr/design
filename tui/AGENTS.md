# Terminal component library

- This directory owns reusable TUI components and their normative usage contracts.
  Read README.md, foundations.md, dropdown.md, bindings.md and wording.md before changes.
- Cross-project W/I/U rules retain their existing owners in ../../specs; link
  them rather than maintaining competing copies. TUI-A/TUI-S/TUI-D/TUI-K live here. New controls reuse the canonical key
  families; change handlers, hints, Help and regression tests together.
- Keep shared Rust widgets independent of application state, networking, settings
  files and provider operations. Accept values/styles; adapters own interactions.
- Applications import shared components. Fix the component instead of copying
  its rendering code or adding an application-specific visual exception.
- Every catalogue entry states whether its code is shared here or still in the
  application. Do not describe a usage contract as an implemented Rust export.
- Preserve required errors, unknown outcomes, visible focus and keyboard access.
  No routine provider credits, empty optional groups or current-value prose tags.
- Use the existing Ratatui version; justify new dependencies. Test real buffer
  coordinates/styles, small grids, Unicode, monochrome and selected/unselected
  states. Use fixtures and temporary files; no live network or preference changes.
- Keep example/gallery output generated by the actual component. Update affected
  adapters, docs and integration tests together. Report evidence limits honestly.
