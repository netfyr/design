Text and diagrams

01 / Text

Text styles

Use Sans for text and headings. Keep normal tracking and kerning enabled. Begin ordinary text at 1.5em line height, especially with stacked accents.

font-family: "netfyr sans", sans-serif;
font-weight: 400;
line-height: 1.5;
letter-spacing: normal;
font-kerning: normal;
02 / Code

Code and diagrams

Use Mono for aligned code and connected cells. Preserve spaces, use 1.25em line height for joined diagrams, and leave letter spacing at zero.

font-family: "netfyr mono", monospace;
font-weight: 400;
line-height: 1.25;
letter-spacing: 0;
white-space: pre;

Weights and styles

Weightnetfyr sansnetfyr mono

Use a supplied weight or italic file. Never synthesize bold or shear an upright to approximate an italic. These are static, unhinted fonts.

Spacing

Leave at least 16 SVG units (u) around the visible artwork. Keep the supplied 32-unit gap (2u) between the flame and wordmark.

The n aligns with the smaller flame tip; the y aligns with the bottom of the flame.

Keep the flame upright with a transparent interior. Minimum size: 16 px; prefer 24 px or larger. Leave clear space of at least one eighth of its SVG viewport.
