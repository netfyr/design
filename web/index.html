Use in a project

Load the stylesheet, wrap your controls in .ui, and initialize the interactive components.

HTML
<link rel="stylesheet" href="./src/components.css">
<main class="ui">…</main>
<script type="module">
  import { enhance } from './src/components.js';
  const cleanup = enhance(document.querySelector('.ui'));
</script>
